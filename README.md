A web-based recreation of the classic Super Mario game built entirely from scratch using vanilla web technologies. This project focuses on physics, collision detection, sprite animation, and game loop mechanics without the use of heavy game engines.

**🎮 Play the live game here:** [Mario Game Clone on Render](https://mario-game-clone.onrender.com)

## ✨ Features

*   **Custom Game Engine:** Built a custom 2D physics engine using JavaScript to handle gravity, velocity, and jump mechanics.
*   **Collision Detection:** Accurate environment boundaries and platform interactions.
*   **Sprite Animations:** Smooth rendering of running, jumping, and idle animations.
*   **Responsive Play:** Optimized for browser-based play with real-time keyboard event listeners.
